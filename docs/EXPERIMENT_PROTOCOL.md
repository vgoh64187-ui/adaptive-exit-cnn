# 实验协议 v0.1（预实验阶段）

## 评价问题与选择规则

核心比较为“固定平均计算预算下的分类准确率”。相对于无辅助出口 ResNet-18 的 Conv/Linear MACs 定义预算比；拟定预算 0.55、0.65、0.75、0.85、0.95、1.01。模型、温度和退出阈值仅以训练/验证信息确定。官方测试集不用于更换模块、改训练配方或挑种子。
同时报告各方法完整深度准确率、参数量、各出口路径 MACs。成本超过预算的策略不能标为满足预算。验证选出的策略在测试集实际成本可能漂移，须报告实测值。
预算是分布平均约束，不保证每张图像的硬实时延迟上限。

## 对照与消融

- B0：CIFAR ResNet-18，单出口，标准残差块。
- B1：相同骨干、GAP-linear 多出口，标准置信度退出（BranchyNet 风格的本地对照，不冒充原论文完整复现）。
- B2：相同骨干、近似等参数 MLP 多出口，容量对照。
- M0：相同骨干、局部—全局融合出口，普通置信度退出。
- M1：M0 权重，增加因果相邻出口一致性策略；无需重新训练。
- M2：融合头与自蒸馏；单独量化训练辅助贡献。
- 固定深度对照：同一多出口网络固定选某个出口（标清共享训练），以及必要时单独训练的截断骨干（标清独立训练）。

每一已训练多出口网络同时评价 confidence/consensus 两种策略，避免把策略收益与结构收益混淆。等容量对照报告实际参数差，不声称完全相同。

## 数据

CIFAR-100 官方训练集分层为 45,000 训练、2,500 温度校准、2,500 策略选择；固定 split_seed=20261031，记录索引 SHA256。训练期间用两验证子集合并的 5,000 样本选择 checkpoint；校准/策略参数在训练结束后拟合，不利用测试标签。主模型种子 17/42/73，不更换数据划分。
训练增强：padding=4 的随机裁剪和随机水平翻转。测试/验证不增强；所有方法相同。当前标准化采用固定公开常用均值方差，明确不是从测试集估计。

## 候选训练配方

SGD、momentum=0.9、Nesterov、weight_decay=5e-4、lr=0.1、5 epoch warmup + cosine、160 epochs、batch=128、AMP。预实验可使用 5/20 epoch，但不得当作最终性能。
所有结构相同交叉熵配方：多出口各项取均值。M2 另加 KL 蒸馏（T=3，系数初始 0.5），最终出口 teacher.detach。
单出口按验证准确率选择 checkpoint；多出口按验证各出口准确率均值选择。固定选择标准，保留末轮 checkpoint 以便核对。

## 统计与真实执行

主要结果各 seed 报告，汇总使用均值和样本标准差，不能把不同样本数量当成独立训练重复。
MACs 包括 Conv/Linear 和空间加权汇聚；不含 BN、激活、常规 pooling、softmax、路由开销。约定 1 MAC=2 FLOPs；真实 latency 则包含模型内上述开销。
分别测试 CPU（固定线程数）与本机 GPU，batch=1 为交互延迟，较大 batch 为吞吐；预热、同步、固定数据、重复测量。GPU CPU host synchronization 计入动态实现时间。
所有精度/预算策略基于全量固定测试集，latency 可用预先固定的代表样本子集，但必须保存 sample IDs，不用最快样本挑选。
报告 p50/p95 与均值；数据加载/预处理是否计入需明确。理论 MACs 节省不能转换成未经测量的时间/能耗节省。

正式部署测量预先固定为 `configs/benchmark_matrix.json`：使用 seed 42 的五种训练结构，在 CPU/GPU、批量 1/32 下测量；另对融合+蒸馏模型测量三个预算的一致性策略及完整骨干路径。每项使用相同的 256 张验证策略选择集样本、32 次预热、3 次重复和 6 个 CPU 线程。计时重复不等于独立训练种子；批量 32 的分位数基于 24 次批处理观测。完整路径跳过辅助头，应与顺序执行辅助头的最终出口控制区分。所有主训练及冻结测试完成、训练队列停止后才进行正式计时。

## 测试前冻结与可靠性诊断补充（尚未解封测试）

完整清单为 `configs/main_queue.json`，共五组模型、每组三个种子。`freeze_protocol.py` 核对完整训练日志、验证缓存、源文件哈希及清单一致性，并将权重、温度/阈值、配置和评估代码的哈希写入 `docs/protocol_lock.json`。目前尚未产生正式锁文件，先完成验证开发和训练。

固定出口 1/2/3 为共享训练网络的控制条件；前序辅助头照常执行，以与累计路径计算量口径一致。它们不能表述为单独训练的最优截断网络。

概率诊断包括 15 个等宽置信度分箱的 ECE、多类别 Brier 分数和 NLL；ECE 空箱跳过，按样本数加权。验证诊断限于策略选择子集，排除温度拟合子集。风险—覆盖率按各出口置信度降序排序，明确其为单出口诊断，不替代真实动态路由。

错误转移均以全部样本数为分母：有害早退是“提前预测错误而同网络最终出口正确”；有益早退是“提前预测正确而最终出口错误”。动态准确率减去同权重最终出口准确率，等于有益比例减去有害比例。这一分解解释退出决策对识别的影响，不混同于相对独立单出口基线的提升。

增加预先固定的纯相邻一致性控制：禁用第一个出口的退出，第二出口在类别一致时退出，不以测试结果调阈值。其对应固定第二出口的对照同样执行两次分类头，用于隔离一致性判据本身的作用。
